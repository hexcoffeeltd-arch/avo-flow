# AVO FLOW — ระบบจัดการสต็อกและการขายอะโวคาโด

เว็บแอปคุมคลังผลไม้สด (อะโวคาโด) ยึด **Lot และเลขเอกสาร** เป็นตัวเชื่อม ตั้งแต่สวน → รับเข้า → คลัง → ความสุก → ตีออก/โอน → สาขา/ลูกค้า → บิล
หน้าเว็บเป็นไฟล์ static (GitHub Pages) · ฐานข้อมูล PostgreSQL บน Neon · กฎธุรกิจทั้งหมดอยู่ในฐานข้อมูล

- **ทดลองทันที:** เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ (โหมดทดลอง ข้อมูลจำลอง เลือกบทบาทได้ 7 แบบ)
- **เปิดใช้งานจริง:** ทำตาม [docs/DEPLOY.md](docs/DEPLOY.md)

## หลักการออกแบบข้อมูล

- **ตารางอยู่ใน schema `avo`** ซึ่งหน้าเว็บเข้าถึงตรงไม่ได้ หน้าเว็บเรียกได้เฉพาะฟังก์ชัน `public.api_*` ที่ตรวจสิทธิ์ทุกครั้ง
- **การเปลี่ยนสต็อกทำผ่าน `avo.move()` เพียงจุดเดียว** ฟังก์ชันนี้ล็อกแถวยอดคงเหลือ (row lock) และเขียนสมุดเคลื่อนไหวทุกครั้ง จึงกันจ่ายเกินและกันกดซ้ำได้แม้หลายคนทำพร้อมกัน
- **ระหว่างทางเป็นจุดจัดเก็บจริง (`transit`)**
  - ตีออก: คลังลด ยอดไปอยู่ระหว่างทาง
  - รับจริง: ระหว่างทางลด สาขาเพิ่มเท่าที่รับได้จริง ส่วนที่ขาดกลายเป็นงานตรวจสอบส่วนต่าง
- **เก็บหน่วยแยกกัน** ทั้งกิโลกรัม ตะกร้า และถุง
- **แยกขายกับโอน**
  - การโอนไปสาขาไม่ใช่ยอดขาย
  - การขายตัดออกจากระบบเมื่อลูกค้ายืนยันรับ (จุดเปลี่ยนเจ้าของ)
